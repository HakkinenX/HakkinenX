## Sobre mim

Sou apaixonado por tecnologia, educação e construção de sistemas que resolvem problemas reais. Meus projetos passam por Android com Kotlin, estudos em Java e uma evolução forte para aplicações web completas com Angular, Spring Boot, Supabase/PostgreSQL, Docker e práticas de produção.

Atualmente estou trabalhando em um sistema escolar com foco em:

- gestão acadêmica e administrativa;
- autenticação e escopo por colégio;
- backend Java com Spring Boot;
- frontend Angular moderno;
- banco PostgreSQL/Supabase;
- deploy, Docker, testes, métricas e health checks.
